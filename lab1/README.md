## Описание задания

Разработать программы для решения [биквадратного уравнения](https://ru.wikipedia.org/wiki/Уравнение_четвёртой_степени#Биквадратное_уравнение).

1. Программы должны быть разработаны в виде консольного приложения на языке Python. Разработайте три программы на языке Python:
   1. с применением процедурной парадигмы (использование функций, оператор def);
   2. с применением объектно-ориентированной парадигмы (использование классов);
   3. с применением функциональной парадигмы (сопоставление с образцом).
2. Каждая программа осуществляет ввод с клавиатуры коэффициентов А, В, С, вычисляет дискриминант и ДЕЙСТВИТЕЛЬНЫЕ корни уравнения (в зависимости от дискриминанта).
3. Коэффициенты А, В, С могут быть заданы в виде параметров командной строки. Если они не заданы, то вводятся с клавиатуры в соответствии с пунктом 2.
4. Если коэффициент А, В, С введен или задан в командной строке некорректно, то необходимо проигнорировать некорректное значение и вводить коэффициент повторно пока коэффициент не будет введен корректно. Корректно заданный коэффициент - это коэффициент, значение которого может быть без ошибок преобразовано в действительное число.

## Экранные формы с примерами выполнения программы

Коэффициенты заданы в командной строке:

```console
$ python3 biquadratic_proc.py 1 -5 4
Дискриминант: 9.0
Корни: -2.0, -1.0, 1.0, 2.0

$ python3 biquadratic_oop.py 1 -4 0
Дискриминант: 16.0
Корни: -2.0, 0.0, 2.0

$ python3 biquadratic_func.py 1 0 -4
Дискриминант: 16.0
Корни: -1.4142135623730951, 1.4142135623730951

$ python3 biquadratic_func.py 1 0 4
Дискриминант: -16.0
Нет действительных корней
```

Коэффициенты вводятся с клавиатуры, некорректные значения игнорируются:

```console
$ python3 biquadratic_func.py 1 qwe
Введите коэффициент B:
abc
Введите коэффициент B:
-2
Введите коэффициент C:
1
Дискриминант: 0.0
Корни: -1.0, 1.0
```
